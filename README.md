# ✅ Todo Application

A modern full-stack Todo application for creating, organizing, and managing daily tasks with authentication, reminders, calendar view, search, filters, and a responsive UI.

## 🚀 Features

- 🔐 User Registration & Login
- 📧 Email Verification with OTP
- 🔑 Forgot & Reset Password
- ➕ Create, ✏️ Edit & 🗑️ Delete Todos
- ✅ Complete / Pending Todo Management
- 📅 Due Date & Time
- 🖼️ Upload Todo Images
- 🔍 Search & Filter Todos
- 📆 Calendar View
- 🔔 Task Reminders & Notifications
- 🌙 Dark / Light Mode
- 📱 Responsive Design for Desktop & Mobile

## 🛠️ Tech Stack

**Frontend:** React.js, Vite, CSS3  
**Backend:** Java, Spring Boot, Spring Security, REST API  
**Database:** PostgreSQL, JPA, Hibernate  
**Email:** Gmail SMTP  
**Tools:** Git, GitHub, Postman, Maven

## ⚙️ Run Locally

### Backend

```bash
cd todo-backend
mvnw.cmd spring-boot:run
```
### Frontend
```
cd todo-frontend
npm install
npm run dev
```
